Weekly Report Generator

1 · Load your data

Upload the CSV / Excel export of your Google Sheet (one row per interaction). The file is read inside your browser — only the final report content (totals, top themes, chosen quotes, text) is sent to the server to draw the slides, and nothing is stored.

Your column names can be anything — you map them in step 2. Seeded replies: put the original post in Message and the seeded reply in Response. A numeric Count column is optional (default 1 per row). Several tabs? Combine them into one tab first (see docs).

2 · Map columns & set the period

Column mapping

Required: Channel and Category. Message/Response are needed for the quote tables.

Which values belong to which channel?

Rows whose channel value isn't ticked anywhere are ignored (and counted in the warnings).

Report settings

Leave the previous period empty to auto-use the equally long period right before the start date — trends are only mentioned if that period actually contains data. If your sheet has no dates, leave all dates empty and type the period in step 3.

3 · Review & edit

Numbers, rankings and quotes come straight from your data. Text in [[double brackets]] needs a human (implications, recommendations, notable concerns). Use **bold** for emphasis. Everything below is editable.

4 · Preview & download

Final review checklist

  • Totals and rankings match your source sheet
  • Quotes are the real messages/responses (flagged ones checked)
  • All [[placeholders]] replaced
  • Trends only claimed where a previous period exists
  • Recommendations are labelled as proposals, not approved commitments
  • No customer personal data in quotes or screenshots
